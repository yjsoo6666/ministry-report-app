# 부처별 기준표 자동 취합 앱

여러 부처가 보낸 **한글(hwpx) 파일**을 한꺼번에 올리면, 부처별·구분별 건수를 읽어 **엑셀 기준표**를 만들어 주는 웹 앱입니다.
지난 차수 기준표를 함께 올리면 증감이 들어간 **비교표**도 만들어 줍니다.

> 조달심(혁신제품 지정 심사) 기준표를 차수마다 손으로 옮겨 적던 반복 업무를 줄이려고 만들었습니다.

## 무엇을 하나요?

| 구분 | 내용 |
|------|------|
| 읽는 건수 | 신규지정 · 1차 연장 · 2차 연장 · 지정취소 · 규격추가 |
| 연장 건수 | 접수가 아니라 실제로 **인정된** 건수만 셉니다 |
| 같은 구분 파일이 여럿 | 유형1, 유형2처럼 서로 다른 파일은 숫자를 더합니다 (복사본은 한 번만 셉니다) |
| 못 읽은 칸 | 자동으로 추측하지 않고 "확인 필요"로 표시합니다. 문서의 번호 목록을 세어 "3건이 맞나요?"라고 **제안만** 하고, 담당자가 눌러야 채워집니다 |
| 결과물 | 기준표 엑셀(표 + 그래프 2개), 비교표 엑셀(증감 표 + 그래프 1개) |

## 화면은 3단계입니다

1. **파일 올리기** — 한글 파일을 끌어다 놓습니다. (선택) 지난 차수 기준표 엑셀을 올리고 이번 조달심 차수를 적습니다.
2. **확인하기** — 읽지 못한 칸이나 확인할 파일만 카드로 보여 줍니다. 숫자를 직접 적거나 빈칸·제외로 정리하고, 표에서 칸을 눌러 고칠 수도 있습니다 ("계"는 자동 재계산).
3. **완성** — 구분별 합계와 증감을 보고 기준표·비교표 엑셀을 각각 내려받습니다. 이름이 바뀐 부처는 "같은 부처인가요?"라고 물어봅니다.

## 개인정보와 보안

- 한글 파일은 **브라우저 안에서만** 읽습니다. 서버나 외부 서비스(AI 포함)로 보내지 않고, 앱에 저장하지도 않습니다. 새로고침하면 모두 사라집니다.
- 건수는 코드로 직접 셉니다. 외부 AI에 파일 내용을 보내지 않습니다.
- 이 저장소에는 **실제 부처 파일이 없습니다.** `samples/`에는 설명서와 가짜 숫자 예시만 있고, 예시 한글 파일은 아래 명령으로 직접 만들어 씁니다.
- 업로드 크기 제한, 압축 폭탄 방어, 엑셀 수식 주입 방어, 보안 헤더(CSP 등)를 적용했습니다.

## 직접 실행해 보기

```bash
npm install           # 처음 한 번만
npm run dev           # 개발 서버 → http://localhost:3000
npm run samples:40    # 가짜 예시 한글 파일 40개를 samples/예시40 에 만들기
npm run samples:check # 확인 카드를 시험하는 파일 2개를 samples/확인용 에 만들기
```

예시 40개를 한꺼번에 올리면 계가 신규지정 69, 1차 연장 45, 2차 연장 58, 지정취소 43, 규격추가 18이 나와야 합니다.

| 명령 | 하는 일 |
|------|---------|
| `npm run build` | 배포용 빌드 |
| `npm run lint` | 코드 검사 |
| `npm test` | 읽기·계산·엑셀이 맞는지 자동 시험 (Vitest) |
| `npm run check -- "<파일 또는 폴더>"` | 내 컴퓨터에서만 파일을 읽어 결과를 글자로 확인 (어디로도 보내지 않음) |

## 기술

Next.js 16 (App Router) · React 19 · TypeScript(strict) · Tailwind CSS 4 · ExcelJS(엑셀) · JSZip(hwpx 풀기, 엑셀 그래프 넣기) · Vitest

## 폴더 안내

| 위치 | 내용 |
|------|------|
| `app/` | 화면 (`page.tsx`, `_components/`) |
| `lib/reader/` | 한글 파일에서 글자 꺼내기 |
| `lib/parse/` | 부처명·구분·건수 읽기 |
| `lib/table/` | 표 합치기, "계" 계산, 칸 수정, 비교표 계산, 부처 이름 짝 맞추기 |
| `lib/excel/` | 엑셀 만들기·읽기·그래프 |
| `scripts/` | 가짜 예시 파일 만들기, 읽기 확인 도구 |
| `tests/` | 자동 시험 |

기획과 규칙은 [PRD.md](PRD.md), 만든 순서는 [PLAN.md](PLAN.md), 구조는 [DESIGN.md](DESIGN.md), 점검 기록은 [CHECK.md](CHECK.md)에 있습니다.

## 아직 안 된 것

- 구형 `.hwp` 파일 읽기 — 한글에서 `.hwpx`로 다시 저장해서 올려야 합니다.
- 실제 부처 파일로 숫자가 100% 맞는지 확인하는 일 — 가짜 예시로만 시험했습니다.
- 내려받은 엑셀을 실제 엑셀 프로그램에서 열었을 때의 그래프 모양 확인.

## 배포

Vercel로 배포합니다. 내부 업무용이라 Vercel 로그인으로 접근을 제한했습니다. 앱은 환경 변수나 API 키를 쓰지 않습니다.
